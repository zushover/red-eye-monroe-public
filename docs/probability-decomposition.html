下一步模型方向

  1. 停止把“气温中心 MAE 变好”直接转换为较高交易权重；先独立校准每个真实市场档。
  2. 固定城市、当地阶段、单位和档宽，使用层级多项 Logit/有序概率模型；稀疏城市向气候区和机场类型收缩。
  3. 把市场共识作为基线或先验，只允许天气特征预测其残差；必须在全新日期上同时降低 Log loss/Brier，才算提供增量信息。
  4. 通过概率门槛后，再用真实盘口深度、成交失败和双边费用做事件级交易回放。
